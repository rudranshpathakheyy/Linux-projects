# Linux Server Management

## 📌 Project Overview

This project is a Bash-based Linux Server Management Toolkit.

It provides a simple menu-driven script to perform common server administration and troubleshooting tasks from the terminal.

## 🛠️ Technologies Used

- Linux
- Bash Shell
- systemctl
- journalctl
- ip
- nslookup
- ss

## ⚙️ Features

- Check service status
- Start a service
- Stop a service
- Restart a service
- Enable service at boot
- View recent system logs
- Check system errors
- Show IP information
- Show routing table
- Perform DNS checks
- Check listening ports

Give execute permission:
